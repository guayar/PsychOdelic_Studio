# Workflow LTX (lipsync)

Ten katalog powinien zawierać workflow LTX. Studio go NIE wymyśla.
Produkcja używa pliku `oug_ltx_director_api.json` z `ComfyUI/user/default/workflows/` (skrypt `gen_ltx_lip.py`).
Skopiuj go tutaj albo podaj instalatorowi (`--ltx-workflow ŚCIEŻKA`), żeby trafił do ComfyUI bez zmian.
